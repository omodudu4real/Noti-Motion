# Slide Notify

Configurable slide-in animation for GNOME Shell notification banners.
Choose the direction, speed, distance, and bounce.

## Install

    git clone https://github.com/omodudu4real/Noti-Motion.git ~/.local/share/gnome-shell/extensions/slide-notify@omodudu
    glib-compile-schemas ~/.local/share/gnome-shell/extensions/slide-notify@omodudu/schemas/

Log out and back in, then:

    gnome-extensions enable slide-notify@omodudu

## Settings

    gnome-extensions prefs slide-notify@omodudu

## Tested on

- GNOME 50 (tested)
